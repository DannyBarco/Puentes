# Puentes
Repositorio para la clase de Puentes


## Calculadora de cargas móviles

Programa web para una viga simplemente apoyada: tabla de cargas, cortante, momento, envolventes y exportación CSV.

Descarga [Puentes-programa.zip](Puentes-programa.zip), extráelo y consulta [USO.md](USO.md) para ejecutarlo en tu computadora o publicarlo como sitio estático. No requiere instalar paquetes para usarlo.

Pruebas numéricas: `node --test tests/beam.test.mjs`. Validación y limitaciones: [REVISION.md](REVISION.md).
